# Stroke-data-documentation
R scripts and data documentation for the analysis of inpatient stroke medical records from five tertiary hospitals providing acute stroke care in Uganda, 2023–2025.

## Overview
This repository contains the R scripts used to assess the completeness and accessibility of inpatient stroke medical records across five tertiary hospitals in Uganda.

## Data
The analysis used routinely collected inpatient stroke medical record data from five tertiary hospitals for the period 2023–2025. The underlying patient-level data are not included in this repository because they are subject to ethical, confidentiality, and data access restrictions.
A data dictionary describing the variables used in the analysis is provided in the repository.

## Analysis
The R scripts include procedures for:
* Data preparation and cleaning
* Variable recoding and standardization
* Assessment of data completeness
* Descriptive analysis
* Comparison of completeness across study sites

## Software
The analysis was conducted using R version 4.6.

## Reproducibility
The scripts and data dictionary are provided to support transparency and reproducibility of the analytical workflow. Because the underlying patient-level data are not publicly available, the complete analysis cannot be independently reproduced without authorized access to the source data.

## Code availability
The R scripts and data dictionary are publicly available in this repository. The underlying patient-level medical record data are not publicly shared due to confidentiality and data access restrictions.
